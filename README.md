# me

임수지의 자기 소개 페이지입니다. 
안녕~! 사람을 이해하고, 끝까지 해내는 실행형 커뮤니케이터 수지의 자기 소개 페이지입니다. 
사람을 이해하고 상황에 맞게 소통하는 능력을 강점으로, 다양한 경험 속에서 책임 있게 역할을 수행해왔습니다. 과외와 도우미 활동을 통해 상대의 필요에 맞춰 설명하고 돕는 법을 익혔고, 동아리 임원 경험을 통해 조직 안에서 협업과 운영을 경험했습니다. 꾸준함을 바탕으로 맡은 일은 끝까지 해내며, 안정적으로 성과를 만들어내는 실행력을 갖추고 있습니다. 앞으로도 사람과 조직을 잇는 커뮤니케이션 역량으로 실질적인 가치를 만들어가고자 합니다.

다양한 인문·예술 분야의 학습을 통해 콘텐츠와 메시지를 구조적으로 분석하는 역량을 길러왔습니다. 비판적 사고를 기반으로 공연예술사, 서양미술사, 현대시인론 등을 탐구하며, 동일한 콘텐츠라도 전달 방식과 맥락에 따라 소비자의 해석과 반응이 달라진다는 점을 발견했습니다. 이러한 문제의식을 바탕으로 기초마케팅 수업에서는 타깃에 맞는 메시지 설계와 커뮤니케이션 전략에 집중하며, ‘어떻게 전달할 것인가’에 대한 고민을 확장해왔습니다. 더 나아가 코퍼스 분석 강의를 두 차례 수료하며 언어 데이터를 기반으로 표현과 반응을 분석하는 경험을 쌓았고, 이를 통해 감각이 아닌 근거 중심으로 메시지를 설계하는 태도를 갖추게 되었습니다. 콘텐츠를 해석하는 시선과 데이터를 기반으로 한 분석력을 바탕으로, 효과적인 메시지를 설계하는 마케터로 성장하겠습니다.
